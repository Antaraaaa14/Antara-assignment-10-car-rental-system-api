## 📌 1. Objective & Overview
A production-ready Car Rental & Vehicle Fleet Management REST API built with Node.js, Express, and Supabase (PostgreSQL & Auth). 

### Key Features & Implementation:
- **Relational Schema**: Vehicles and Rentals relational PostgreSQL tables with foreign key constraints, checks, and timestamps.
- **Date Collision Prevention**: Strict date overlap validations preventing double-booking of vehicles (`existing.start_date <= requested.end_date AND existing.end_date >= requested.start_date`).
- **Dynamic Cost Calculation**: Automated calculation of rental day span (`days * daily_rate`) on the backend.
- **Vehicle State Management**: Lifecycle transitions (`available` ➔ `rented` ➔ `maintenance` ➔ `available`).
- **Supabase Authentication**: Secure JWT Bearer token authentication protecting rental creation, user booking history, and management endpoints.
- **Relational Joins**: Vehicle details returned with booking history, and bookings returned with vehicle details.

## 🗄️ 3. Supabase Database Schema

Execute the following SQL in your Supabase SQL Editor:

```sql
-- 1. Vehicles Table
CREATE TABLE vehicles (
    id BIGINT GENERATED BY DEFAULT AS IDENTITY PRIMARY KEY,
    brand TEXT NOT NULL,
    model TEXT NOT NULL,
    year INT NOT NULL,
    category TEXT NOT NULL CHECK (category IN ('Sedan', 'SUV', 'Luxury', 'Hatchback', 'Electric')),
    daily_rate NUMERIC(10, 2) NOT NULL CHECK (daily_rate > 0),
    fuel_type TEXT NOT NULL,
    seating_capacity INT NOT NULL DEFAULT 5,
    status TEXT NOT NULL DEFAULT 'available' CHECK (status IN ('available', 'rented', 'maintenance')),
    created_at TIMESTAMP WITH TIME ZONE DEFAULT NOW()
);

-- 2. Rentals / Bookings Table
CREATE TABLE rentals (
    id BIGINT GENERATED BY DEFAULT AS IDENTITY PRIMARY KEY,
    user_id UUID NOT NULL, -- references Supabase auth.users
    vehicle_id BIGINT REFERENCES vehicles(id) ON DELETE RESTRICT,
    customer_name TEXT NOT NULL,
    customer_email TEXT NOT NULL,
    start_date DATE NOT NULL,
    end_date DATE NOT NULL,
    total_cost NUMERIC(10, 2) NOT NULL,
    status TEXT NOT NULL DEFAULT 'booked' CHECK (status IN ('booked', 'active', 'completed', 'cancelled')),
    created_at TIMESTAMP WITH TIME ZONE DEFAULT NOW(),
    CONSTRAINT valid_date_range CHECK (end_date >= start_date)
);
```

## 📋 5. API Endpoints Specification

### 🔐 Authentication (`/api/auth`)
| Method | Endpoint | Auth | Description | Request Body Example |
|---|---|---|---|---|
| `POST` | `/api/auth/register` | Public | Register customer with Supabase Auth | `{"email":"driver@travel.com","password":"mypassword123","name":"David"}` |
| `POST` | `/api/auth/login` | Public | Login & receive Supabase JWT token | `{"email":"driver@travel.com","password":"mypassword123"}` |
| `GET` | `/api/auth/profile` | Bearer Token | Get current user's profile | None |

### 🚗 Vehicle Fleet Management (`/api/vehicles`)
| Method | Endpoint | Auth | Description | Query / Request Body |
|---|---|---|---|---|
| `GET` | `/api/vehicles` | Public | Fetch all vehicles (supports filters) | Query: `?category=SUV&status=available&brand=Tesla&min_rate=2000` |
| `GET` | `/api/vehicles/:id` | Public | Get vehicle details with past rentals | None |
| `POST` | `/api/vehicles` | Bearer Token | Add new vehicle to fleet | `{"brand":"Tesla","model":"Model 3","year":2024,"category":"Electric","daily_rate":4500,"fuel_type":"EV","seating_capacity":5}` |
| `PUT` | `/api/vehicles/:id` | Bearer Token | Update vehicle rate or status | `{"daily_rate":4800,"status":"maintenance"}` |
| `DELETE`| `/api/vehicles/:id` | Bearer Token | Delete vehicle from fleet (checks active bookings) | None |

### 📅 Rental & Booking Operations (`/api/rentals`)
| Method | Endpoint | Auth | Description | Request Body Example |
|---|---|---|---|---|
| `POST` | `/api/rentals` | Bearer Token | Book vehicle (Collision check & price computation) | `{"vehicle_id":1,"start_date":"2026-05-01","end_date":"2026-05-05","customer_name":"David","customer_email":"david@test.com"}` |
| `GET` | `/api/rentals/my-bookings`| Bearer Token | List bookings for authenticated user | None |
| `PATCH`| `/api/rentals/:id/cancel`| Bearer Token | Cancel upcoming rental | None |
| `PATCH`| `/api/rentals/:id/complete`| Bearer Token | Complete rental & set vehicle available | None |

## 🧪 6. Testing Guide

1. **Register & Login**:
   ```bash
   POST http://localhost:5000/api/auth/register
   Content-Type: application/json
   { "email": "david@test.com", "password": "password123", "name": "David" }
   ```

2. **Add a Vehicle**:
   ```bash
   POST http://localhost:5000/api/vehicles
   Authorization: Bearer <ACCESS_TOKEN>
   {
     "brand": "Tesla",
     "model": "Model 3",
     "year": 2024,
     "category": "Electric",
     "daily_rate": 4500,
     "fuel_type": "EV",
     "seating_capacity": 5
   }
   ```

3. **Book Vehicle #1 for 2026-05-01 to 2026-05-05**:
   ```bash
   POST http://localhost:5000/api/rentals
   Authorization: Bearer <ACCESS_TOKEN>
   {
     "vehicle_id": 1,
     "start_date": "2026-05-01",
     "end_date": "2026-05-05",
     "customer_name": "David",
     "customer_email": "david@test.com"
   }
   ```
   **Response (201 Created)**: Total cost calculated as 5 days × ₹4500 = ₹22,500.

4. **Attempt Overlapping Booking (2026-05-03 to 2026-05-07)**:
   ```bash
   POST http://localhost:5000/api/rentals
   Authorization: Bearer <ACCESS_TOKEN>
   {
     "vehicle_id": 1,
     "start_date": "2026-05-03",
     "end_date": "2026-05-07",
     "customer_name": "Alice",
     "customer_email": "alice@test.com"
   }
   ```
   **Response (400 Bad Request)**:
   ```json
   {
     "success": false,
     "message": "Vehicle already reserved during this timeframe."
   }
   ```
